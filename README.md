# Proyecto-Optimizacion-Numerica--Regresi-n-Lineal-y-No-Lineal-M-ltiple
Implementación y comparación en Python de los métodos de optimización de Newton y Trust Region para regresión lineal y no lineal múltiple. Predicción de desgaste de herramientas CNC minimizando errores cuadráticos sin inversión explícita de matrices.
